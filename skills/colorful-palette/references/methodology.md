# 色彩基础知识 · 配色方法论

> 来源:《配色设计速查手册》第1章

## 1. 色彩三要素

任何色彩都具有三个基本要素,分别表示色彩的相貌、深浅程度与鲜艳程度。

- **色相**:色彩的首要特征,是区别不同色彩最准确的标准。初学者可通过十二色相环辨认色相,它解决了色彩纷乱易混淆的问题,并包含多种色彩关系。
- **明度**:可理解为"亮度"。明度越高越接近白色,越低越接近黑色;黄色明度最高,紫色明度最低。明度在三要素中独立性较强,可不带色相特征、单独通过黑、白、灰体现(如素描只看明暗)。
- **纯度**:色彩的鲜艳程度,又称饱和度。纯度降低时色彩会变为明度相似的灰色;纯度受明度影响,明度提高或降低都会使纯度降低。

## 2. 十二色相环与色彩关系

色相环由三原色及其混合产生的间色、复色按规律排列成闭环,是配色的核心工具。绘画颜料三原色为红、黄、蓝;RGB 模式三原色为红、绿、蓝(电子屏用);CMYK 模式三原色为品红、黄、青(印刷用)。

| 色彩关系 | 夹角 | 说明 |
| --- | --- | --- |
| 对比色 | 120°~180° | 对比强烈、醒目、鲜明,如红与蓝、蓝与橙、绿与紫 |
| 互补色 | 180° | 对比效果最强烈,如黄与紫、红与绿、蓝与橙 |
| 中差色 | 60°~90° | 对比丰富、活泼,同时保持协调统一,如蓝与黄绿、黄与青蓝 |
| 类似色 | 约 60° | 对比协调、柔和、耐看,室内设计常用,如红与橙、蓝与绿 |
| 邻近色 | 30° 内 | 色相环中相邻的色彩,同色系内通过明度、纯度对比可强化效果 |
| 冷暖色 | — | 红、橙、黄为暖色(源于阳光、烈火);蓝、青为冷色(源于海水、冰雪);以紫和绿为界,二者为中性色,蓝与橙为冷暖对比最强烈的色彩 |

## 3. 色调

色调将明度与纯度结合起来表现色彩的程度,是设计中把握情感表达的重要概念。

- **明鲜色调**:鲜艳、纯度高,配色多样。多彩强对比意象热烈、刺激、张扬;配对比色更有活力;与白色搭配欢乐、积极、开放,与黑色搭配激情、力量、自信。
- **明色色调**:在明鲜色调基础上提高明度,少了刺激与艳丽,整体干净、协调。对比色组合可爱、梦幻、充满童趣;中差色组合舒适、阳光、年轻;同色系组合干净、明朗。
- **明淡色调**:轻柔、淡雅,纯度低、明度高。暖色系组合温柔、浪漫、放松亲和;冷色系组合冷淡、寂静。
- **浊色色调**:成熟、中庸素雅,纯度低、色彩倾向极弱。对比色组合力量感较强,成熟优雅并存,格调与成年人一致。
- **暗浓色调**:明度低、纯度高,是独特的色调。对比色组合带成年人高级趣味,无明鲜色调的刺激却不失力量感,给人成熟、高级、有魅力之感(常用于奢侈品、高端产品广告)。
- **暗色色调**:在黑色中蕴藏色彩力量,色彩明度低。深色系组合体现商务、内敛;搭配不同明度可带神秘感与戏剧性。

## 4. 色彩的心理效果

色彩对心理的影响源于记忆、认知的联想和心理暗示。一种颜色可有多种倾向,需通过配色让色彩共同发挥作用来控制心理效果。

- **暖色**:红、橙、黄等源于阳光、烈火的色彩,给人温暖、热烈之感。如红色代表喜庆、热闹、吉祥,黄色令人联想到积极向上的阳光。
- **冷色**:蓝、青等源于海水、冰雪的色彩,给人寒冷、宁静之感。
- **中性色**:紫与绿为界,处于冷暖之间,兼具过渡与平衡作用。

## 附:配色小技巧

- **控制色彩数量**:主色不宜超过三种,通过增减明度、纯度来丰富配色,意象是否准确直观比色彩多少更重要。
- **弱化冲突**(如红配绿):高纯度色彩各自性格突出会导致意象杂乱,可通过改变明度、纯度来调和;提升明度显年轻愉快,降低明度显高级成熟。
- **色彩面积**:意象倾向于面积较大的色彩;但明度差异大时,意象倾向鲜明的色彩(鲜明色彩力量强、醒目)。
- **黑、白、灰调和**:配色对比不稳时,添加黑、白、灰可既保留活力又使对比协调稳定。
- **总结**:配色原则是在色彩对比中寻找平衡,让色彩传达准确的意象与美感;配色技巧是经验方法而非绝对,需打破常规、摆脱束缚。
