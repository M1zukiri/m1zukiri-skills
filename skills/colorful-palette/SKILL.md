# Colorful Palette 配色方案速查

## Overview

基于《配色设计速查手册》(红糖美学著,人民邮电出版社)构建的配色知识库,覆盖 **7 大色系、162 类意象配色、52 类大自然配色、20 种流行风格配色**,共 **1583 个配色方案**(含双色、三色、四色、五色)。所有色值(CMYK + RGB)均提取自书中印刷色号,以书为准;HEX 由 RGB 确定性转换,是派生值。

## When to Use

- 用户在设计流程中需要配色方案:海报、PPT、UI/网页、Logo、插画、品牌视觉、报告美化等
- 用户提到:配色、颜色、颜色搭配、色系、色值、主题色、主色/辅色、色卡、调色、palette、color scheme、colors、colour、色号
- 用户给出场景/情感/风格描述,希望得到具体颜色建议(如「温暖的配色」「科技感配色」「森林色系」「复古风格」)
- 需要「以印刷色号为准」的严谨色值(CMYK + RGB),而非凭感觉给色值

## 使用流程

1. **理解需求**:明确设计主题、情感倾向(温暖/冷静/活力/优雅)、风格(复古/科技/自然)、目标受众。
2. **掌握原则**:读 `references/methodology.md`,回顾色彩三要素、色彩关系(对比/互补/类似/邻近)、色调、心理效果,作为选色的理论依据。
3. **检索方案**:按需求定位到 references 对应文件(见下表),挑选 1-3 个匹配方案;优先选意象/风格匹配情感需求的,再选色系匹配的。
4. **输出方案**:按「输出契约」给出完整配色方案,附方法论依据。

### references 检索指南

所有数据文件标题统一为 `## <名称>·<双色|三色|四色|五色>配色`,按色值行格式 `- <色名>: CMYK c-m-y-k · RGB r-g-b` 组织。

| 需求 | 文件 |
| --- | --- |
| 配色方法论、色彩关系、色调、心理效果 | `references/methodology.md` |
| 红色系(喜庆、热情、强烈) | `references/red.md` |
| 橙色系(活力、温暖、美味) | `references/orange.md` |
| 黄色系(阳光、明亮、积极) | `references/yellow.md` |
| 绿色系(自然、清新、安定) | `references/green.md` |
| 蓝色系(冷静、专业、悠远) | `references/blue.md` |
| 紫色系(神秘、优雅、浪漫) | `references/purple.md` |
| 无色彩系(黑白灰、简约、高级) | `references/achromatic.md` |
| 情感意象(温暖、浪漫、活力、优雅等 162 类) | `references/imagery.md` |
| 大自然场景(幽静森林、碧海细沙、天空之梦、粉霞天空等 52 类) | `references/nature.md` |
| 流行风格(文艺复兴、北欧风、赛博朋克、故障艺术等 20 种) | `references/style.md` |

检索技巧:

- **同色名多方案**:同一 `色名·X色配色` 标题下有多个方案(色系文件每色名 10 个方案:4 双色 + 6 三色;意象/自然/风格每类 2 个:双色 + 三色)。按方案在标题下出现的顺序记为「第 N 组」(第 1 个该标题条目为第 1 组),据此定位与引用。
- **编号与来源**:`编号` 字段存在三种情况——red(001-012)、green(037-048)、purple(061-072)为系内编号;imagery(079-240)、nature(241-292)、style(293-312)为全书连续编号;orange、yellow、blue、achromatic 的编号为「无」。编号用于溯源,不能唯一标识单个方案(一个编号对应一组方案)。
- **同名意象**:imagery 中存在同名不同意象(如「枯萎」有编号 132、166 两个),按编号口径共 162 类,按名称去重为 161 种;检索时以编号区分,不要混用。
- **标签检索**:`标签: 无` 的条目应跳过按标签筛选,改用说明或色名检索;yellow/blue/orange/red/imagery 部分条目无标签。
- **缺值条目**:遇 `CMYK 缺`(仅少数)或说明/标签为「无」的条目,如实处理,规则见「数据完整性说明」。

## 输出契约

给配色方案时,**必须**按此格式输出:

```
## <色名>·<配色数>配色(第 N 组)
- 适用场景: <一句话,来自意象/风格说明;说明为「无」时按色彩关系推断并标注「推断」>
- 情感标签: <如:温暖、活力、优雅;标签为「无」则省略>
- 色值:
  - <色名>: CMYK c-m-y-k · RGB r-g-b · HEX #rrggbb
  - 搭配色N: CMYK c-m-y-k · RGB r-g-b · HEX #rrggbb
- 方法论依据: <一句>
```

规则:

1. **唯一标识**:标题行必须含「色名」「配色数」和「第 N 组」,确保用户能准确回查 references(同色名多方案时不会混淆)。如 `## 樱花色·双色配色(第 2 组)`。
2. **色值以书中 CMYK/RGB 为准**,不得臆造或修改;HEX 由 RGB 确定性换算。
3. **三色缺第 3 色块**:仅意象/自然/风格文件的三色条目只含 2 个色值(源书扫描件限制),如实输出已有色值,并在结尾注明「第 3 色缺失(源书限制)」;若用户需要完整三色,按方法论建议同色系邻近色补充,并明确标注为「建议补充色」。
4. **说明为「无」**(yellow/blue 部分条目):不得编造适用场景;按色彩关系(对比/类似/邻近)与色调(明鲜/明浊等)给方向,标注「推断」。
5. **标签为「无」**:省略情感标签项。
6. **CMYK 缺 条目**:如实输出已有 RGB 与缺失标注,建议用户用同色系近似色补充,并明确标注「补充色」。
7. **多方案呈现**:若用户需求与方案不完全匹配,给出 2-3 组备选(注明各自第 N 组与差异),让用户选择。
8. **方法论依据**:输出后附一句色彩关系依据(如「该方案用邻近色,整体协调柔和」),引用 methodology.md 的概念。

### 示例

用户需求:「做一个温暖的生日海报配色,想要甜美的感觉」。

```
## 樱花色·双色配色(第 1 组)
- 适用场景: 樱花色高明度带来晴朗新鲜感,与明度高、纯度低的暖色搭配,清新而有青春活力
- 情感标签: 清新、青春
- 色值:
  - 樱花色: CMYK 4-8-4-0 · RGB 246-239-240 · HEX #F6EFF0
  - 搭配色1: CMYK 8-47-19-0 · RGB 229-159-171 · HEX #E59FAB
- 方法论依据: 樱花色为高明度暖白,配上低纯度粉调,属明淡色调的类似色搭配,整体轻柔甜美
```

(注:此例出自 `references/red.md` 樱花色·双色配色第 1 组;若用户需要更浓的甜美感,可改用第 2 组或三色条目,并注明差异。)

## 数据完整性说明(必须遵守)

- **三色缺块**:imagery、nature、style 的**全部**三色条目(234 条)仅含 2 个色值(源书扫描件 OCR 限制);其余文件三色/四色/五色条目色值完整。不编造缺失色块。
- **错位修复**:2026-08-26 已按「同方案内 CMYK 与 RGB 重连」修复 46 个方案(色值均为书中原值,仅修正行错配);仍有 58 条(48 方案)疑似错位无法可靠恢复,遇 CMYK 与 RGB 明显不匹配的条目请谨慎使用并说明。
- **缺失字段**:orange/yellow/blue/achromatic 的编号、部分文件的说明/标签为「无」,为源书提取时的真实缺失,不编造、不臆补。
- **搭配色命名**:色系配色的「搭配色」无印刷色名,以「搭配色N」编号;主色保留书中原名。
- **数据修复记录**:详细修复过程见 2026-08-26 审查报告(错位重配对、去重、格式统一、畸形行标注),修复脚本与备份在 skill 目录同级及 tempokiri 工作区可查。

## Common Mistakes

- ❌ 用视觉模型「读色块」猜色号——不可靠;必须用 references 中 OCR 提取的印刷色号。
- ❌ 臆造缺失色值或色名——三色缺第 3 块、CMYK 缺、说明/标签为「无」都要如实说明,不要自创。
- ❌ 只给色值不给场景说明——配色方案的灵魂是「传达什么意象」,必须附情感/适用说明(推断需标注)。
- ❌ 忽略方法论——单纯抛色值不如「方法论依据 + 色值」有说服力,始终引用 methodology.md 的概念。
- ❌ 省略「第 N 组」标识——同色名多方案是常态,不带序号会无法回查,也容易拿错方案。
