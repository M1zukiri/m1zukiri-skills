# 转写校正规则详解

本文件是 `meeting-transcript-correction` 的规则层。`SKILL.md` 只放准则与流程，这里放判定标准、证据等级、错误分类与反例。动手前通读一遍；遇到边界情况回到这里。

## 1. 判定目标

一条转写要不要改，先确认两件事：**目标模式**，以及**这条属于什么错误**。

0. **目标模式**：学术资产模式（默认——产出自己可读、可理解的学术材料，允许在权威来源确认后改正原文的错误）/ 保真模式（逐字引用、审计、争议留痕，只还原听写）。模式不同，对「原文与权威来源不符」的处理不同。
1. **这句话坏在哪里？** 是听写错误（声音→文字）、说话人口误（讲者自己说错）、还是内容本来如此（只是不流畅）？
2. **需要什么证据才能还原或纠错？** 发音、语法、图片、公开来源、用户指定——五类证据里至少有一类。
3. **改完会不会新增无据信息？** 资产模式的纠错也必须落到图片或权威来源；不能借纠错补讲者没讲过的观点、因果或段落。

转写错误始终在修正范围；说话人口误在保真模式保留、在资产模式可订正并标原词；只是风格不顺的，不改。

## 2. 证据等级

| 等级 | 证据 | 用途 | 置信度 |
| --- | --- | --- | --- |
| E1 | 用户明确指定 | 直接改，记录为「用户指定」 | 高（但注明来源） |
| E2 | 同一场次的图片（PPT 页、白板、名牌、背景板） | 专名、术语写法、标题、模型名、数字、结论原句 | 高（逐字可读）/ 中（按片段补全） |
| E3 | 公开权威来源：学校/机构官网、会议官网与议程、论文/DOI/PubMed、标准组织（ITU-T/IEEE/3GPP）、公司官网 | 身份、单位、正式题目、术语、缩写、已发表成果、数据口径 | 高（一手） |
| E4 | 发音/字母序列/词边界/术语近似 | 近音词、缩写、连读、数字读法 | 中/低，通常需上下文配合 |
| E5 | 语法结构（功能词、冠词、介词、系动词、重复词） | 补全被吞掉的结构词 | 中/高（仅限结构词） |
| E6 | 全文内部一致（同一文档另一处、汇总转写、自动纪要） | 交叉核对；只能作为线索 | 中/低 |

规则：**E2/E3 是「可以改」的硬证据；E4/E5/E6 是「可以提出候选」的软证据**。软证据单独成立时，只在能唯一确定且不新增信息时改；否则保留原文并标 `〔?〕`。E2/E3 在保真模式用于听写还原与差异比对，在学术资产模式下还可用于纠错；两种模式都要在依据栏保留原词。

## 3. 准则现行版（v1.2，经用户确认）

> 这是准则本体，优先级最高。v1.0 原文见文末附录，仅存档。

**模式先行**：默认学术资产模式；保真模式用于逐字引用。下面的修改范围与条件两模式共用，差异见「学术资产模式的额外许可」。

### 只针对以下内容进行修正或补充

- 因转写时的词句错误，导致文段的表述与上下文脱节或相冲突的；
- 因转写时的词句丢失，导致文段的表述缺少语法结构、无法通顺理解的；
- 因转写时的识别问题，导致文段中的指标、数据等表述与图片或公开资料明显不符的。
  - 「看起来不符合实际或常识」只能触发存疑标记，不能单独作为修改依据。

### 以下情况可以保留

- 虽然出现了可能的词句错误，但并不能确认其原意，从上下文也无法推断的；
- 丢失了与文段整体主旨相关程度不高的信息，且文段本身的表达仍然相对完整可读的。

### 修改动作至少满足以下条件之一

- 修改后的词汇或语句与原先文本在发音、字母序列、词边界或术语上接近；
- 修改后的词汇或语句没有在原先文本里出现，但属于可唯一确定的语法结构（冠词、介词、系动词、重复词等）；实词补全需另有一类证据；
- 修改后的数据、专名或术语来源于转写中同一部分的图片信息（保真模式下仅用于听写还原；学术资产模式下可用于纠错，须保留原词；按片段补全处标 `〔补〕`）；
- 修改后的数据或表述来源于网络等公开平台上的权威信息，如学校/机构官网、论文主页、标准组织等（学术资产模式下可用于纠错，须注明来源）；
- 修改动作由用户本人指定。

### 学术资产模式的额外许可

在学术资产模式下，若同一场次的幻灯片、论文、标准或官网能确认原文的数据、术语、专名或事实性表述有误，可以直接改正；但必须：

- 在逐句表的「依据」列或脚注保留原词、来源与改动理由；
- 在产物开头声明「学术整理版，非逐字稿」；
- 不把许可用于观点、判断、预测、语气与修辞——这些仍按原话保留；
- 不把外部资料的内容扩写成讲者没讲过的段落。

## 4. 修订记录（v1.0 → v1.2）

**v1.1 的三处修订**

1. **「发音接近」扩展为「发音、字母序列、词边界或术语接近」**。理由：ASR 的错误不只有同音词——缩写（`Ot`→`OLT`）、词边界（`a fan`→`FAN`）、数字读法（`1616`→`16-QAM`）、专名远音（`Jing Wenzhao`→`Junwen Zhang`）都不满足严格同音。此类线索单独使用时置信度不超过「中」。
2. **「语法上唯一确定」限定为功能词与结构词**。理由：语法能唯一确定的是冠词、介词、系动词、重复词等；实词往往有多种补法（`be honest with the channel limit` 可补的动词不止一个），不能仅凭语法猜，必须有图片、权威来源或发音线索。
3. **数据条款从「显然不符合实际或常识」改为「与图片或公开资料明显不符」**。理由：常识会误伤——647M 用户、5580 GHz 增益带宽积、22 个月翻倍都反直觉但正确。常识只触发存疑，改数必须落到 E2/E3；E1 除外。

**v1.2 的模式修订**

4. **「幻灯片只证明页面这样写，不证明讲者这样说」改为模式相关**。保真模式下成立；学术资产模式下过度严格——整理目标是可读、可理解的学术材料，不是逐字复原。因此资产模式允许经权威来源确认后直接改正原文中的数据、术语、专名与事实性表述，但必须保留原词、注明来源、声明口径。观点、判断、语气与修辞不适用。

**三条实施边界**：

- 保真模式下，图片能证明页面/白板上的文字，不能证明讲者的口播，两者分开写；学术资产模式下以权威来源为准，但在依据/脚注保留原词与差异。
- 「可以保留」不等于「可以删除」。读不懂的碎片保留原文并标 `〔?〕`。
- 资产模式的许可不覆盖文风改写、观点补充与外部资料扩写。

## 5. 修改的必要条款（与「至少满足之一」同时成立）

1. **不无据新增**：只做有证据的还原或纠错；不把外部资料整段搬进记录，不替讲者补观点或因果。
2. **最小编辑**：优先改词，其次改短语，最后才改句子；不改可读的风格与口语重复。
3. **区分说话人口误**：保真模式下原样保留，必要时注「讲者原话」；学术资产模式下可订正，但标「讲者口播为 X，按 Y 订正」。
4. **保留原文结构**：不合并/拆分句子，不调整段落顺序，不改说话人归属（除非有独立的声纹证据）。
5. **保留不确定性**：`〔?〕` = 无法复原；`〔…〕` = 补全；`〔补〕` = 按片段补全。三种标记不能混用。
6. **可审计**：每条修改记录位置、原文、校正、类别、证据、置信度；修改前后都能被第三人复算。
7. **来源可追**：公开来源给 URL、标题、访问日期；打不开就写「未找到」，不引用记忆。
8. **术语统一**：同一术语全篇用同一写法；首次出现可给中英对照。
9. **语言不变**：原文是英文就改英文，不翻译；中文夹英文术语保持原样。
10. **下游申报**：改纪要、汇总、发言人表等派生文件时，逐条申报；原始 ASR 不改。
11. **声明口径**：产物开头写明「学术整理版（非逐字稿）」或「逐字保真」；资产模式的订正项保留原词与来源。

## 6. 听写错误分类与处理

| 类型 | 例子（来自真实会议） | 处理 | 需要证据 |
| --- | --- | --- | --- |
| 缩写/字母序列 | `Ot`→`OLT`、`Ou`→`ONU`、`Moe`→`MoE`、`Psnr`→`PSNR` | 改 | 幻灯片/同段术语（E2/E4） |
| 近音词 | `calm`→`QAM`、`fun`→`FAN`、`semantic well`→`semantic-aware` | 改 | 术语 + 上下文（E4/E5/E6） |
| 词边界 | `a fan or a fiber access`→`FAN, or fiber access`、`front hall`→`fronthaul` | 改 | 术语 + 上下文 |
| 数字/单位 | `200 z, 200 z 400 pound`→`200G PON`、`100 G Beyond`→`100G and beyond` | 谨慎改；只改到有证据的程度 | 图片/标准（E2/E3） |
| 专名/机构 | `zhang xun Wen`、`Jing Wenzhao from Shandong University`→`Junwen Zhang, Fudan University` | 改 | 标题页/议程/官网（E2/E3） |
| 术语/模型名 | `SADQAM`（不存在的词）、`SDXL-Turbo`、`Qwen-VL` | 有页面就读页面；拼写不明确保留 `(?)` | 图片（E2） |
| 漏词/重复 | `the the the the connections`、缺冠词/介词 | 改 | 语法（E5） |
| 句间指代断裂 | `Ot side`/`Ou side` 混用导致 OLT/ONU 颠倒 | 改 | 幻灯片架构（E2） |
| 说话人口误 | 讲者把倍率说错、把标准号说错 | 保真：不改，加注；资产：可订正，标原词 | 无需 / 权威来源（资产） |
| 听不清 | `be honest with the channel limit` | 保留 `〔?〕` | 无 |

## 7. 决策树

```text
可疑片段
├─ 先定模式：
│  ├─ 保真：能确定是说话人口误/事实错误吗？──是──> 原样保留（可加注），结束
│  └─ 资产：E2/E3 能证明原文的数据/术语/专名/事实有误吗？──是──> 订正，依据栏保留原词与来源，标「高」，结束
├─ 有 E2（图片）或 E3（权威来源）能直接支持某个听写还原吗？──是──> 改，标「高」
├─ 只有 E4/E5/E6 软证据：
│  ├─ 改法唯一、且只涉及结构词/近音术语/缩写？──是──> 改，标「中」
│  └─ 有多个合理候选，或涉及实词？──是──> 保留原文 + 〔?〕/候选说明，标「低」或「存疑」
└─ 没有任何证据：
   ├─ 不影响理解？──> 保留原文（可不动）
   └─ 影响理解？──> 保留原文 + 〔?〕，列入存疑清单
```

## 8. 数据类修改的额外检查

1. 先找同一场次的幻灯片/白板：柱状图数值、图例、坐标轴、表头、脚注。
2. 图片上的数字要确认：柱顶标签、坐标轴乘数（如 `×10³`）、图例对应、单位（G/Gb/s、km、dB）。
3. 没有图片时，查论文摘要/标准正文；仍没有就写「未找到」，不要把「看起来合理」的数写进去。
4. 数字改了，要连带检查：单位、量级、倍率、百分比、与相邻数字的加总关系。
5. 图片里读不全的数字，宁可标 `(?)`，不四舍五入、不猜测。
6. 同一数字在幻灯片出现两次且不一致时，以更完整的一页为准，并在说明里记录两张图的差异。

## 9. 身份与题目

- **讲者身份**：以标题页署名 + 会议议程 + 机构官网三方交叉；三者不一致时并列写出，不强行统一。
- **机构**：「自我介绍被听成 X 校」不等于「讲者来自 X 校」；查公开履历，履历里没有就判 ASR 误听。
- **题目**：主持人串场口播的题目、幻灯片标题页的题目、会议议程的题目可能是三个东西。保真模式全部保留、分别标注；学术资产模式以标题页/议程为准，但在依据栏保留口播差异。
- **头衔**：职称、实验室、职务以官网为准；不确定的头衔不写。

## 10. 反例（本 skill 的来源案例，切勿重犯）

1. **在保真模式把口播题目替换成幕布题目**：需要逐字引用时，主持人念的题目与标题页不同，直接替换会销毁「两个题目不同」的信息。保真模式：两句都保留，注明来源；资产模式：可以标题页为准，但要在依据栏保留口播原词并声明口径。
2. **借「资产模式」改写文风或扩写**：资产模式的许可只覆盖有权威来源的数据、术语、专名与事实表述；不能拿来润色讲者的话、补讲者没讲的观点，或把论文内容扩写成「讲者大概会这么说」。
3. **用领域先验改术语**：讲者说 `semantic token modulation`，页面标题是 `Semantic-aware token communication`，图 23 又写 `Token-Aware Modulation`。这是三个层级的概念；资产模式只在权威来源能证明「原文术语用错」时改，不能因为页标题「更规范」就替换。
4. **用常识改数字**：`647M` 用户、`5580 GHz` 增益带宽积、`22 个月 → 6 个月` 都可能「看起来反常」，但照片/论文确认后就是对的。常识只能用来标记，不能用来改。
5. **猜测性补全不标**：`we have like 8-bit ___ improvement` 中的 `precision` 是补的，就要用 `〔precision〕`，不能直接写进正文。
6. **为了让句子通顺删掉听不懂的片段**：`be honest with the channel limit` 应保留 + `〔?〕`，不能换成「achieve」之类的「合理」动词。
7. **只改逐句、不改纪要**：自动纪要会继续传播错误；必须同步修订或显式标注「以校正版为准」。
8. **置信度通胀**：把「高」当成默认值。含补全、推断、无法复原的行必须降为「中/低」。
9. **幻灯片读不全就当读到了**：被观众头部遮挡的句子只能按可读片段补，补的部分标 `〔补〕`；不能把补全句写成「幻灯片原文」。

## 11. 多候选与用户裁决

- 若两个候选都满足证据条件：列「首选 / 备选」，说明各自证据，正文用首选并标「存疑」。
- 若证据互相冲突：停手，向用户说明冲突点（例如议程题目与标题页题目不同），由用户指定以哪个为准。
- 用户指定优先于所有其他证据，但仍要记录「用户指定」并保留原词。

## 12. 复核清单（给独立复核者）

- 产物开头是否声明口径（学术整理版 / 逐字保真）？模式与用户的用途是否一致？
- 资产模式的订正项是否都在依据栏保留了原词、来源与理由？有没有借机改写文风或扩写？
- 逐条问：这条修改的证据属于 E1–E6 哪一类？证据能支撑到「含义」还是只能到「语气」？
- 搜「高」置信度行中的「存疑 / 推断 / 无法复原 / 〔」；有则降级。
- 抽查 3 个数字：能否在图片或来源里逐字找到？
- 抽查 2 个专名：官方页面是否支持？
- 检查口播与幻灯片是否被混写：保真模式应并列，资产模式应保留原词与差异说明。
- 检查是否新增了原文没有的事实或因果。
- 检查派生文件是否被静默修改。
- 检查读不懂的碎片是否被删除。
