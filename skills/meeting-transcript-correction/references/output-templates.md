# 产出模板

本文件给三份产物的骨架。可按场次规模删减，但「原始件不改 + 逐条依据 + 存疑清单」三件事不能省。

## 1. `转写_校正版.md`

```markdown
# 第 N 场报告：<主题>（校正版）

> 录音相对时刻 00:00:00 – 00:00:00（时长）· <会议> · <日期>
> 原始转写：[转写.md](转写.md)（保留未改）· 校正依据：[校正说明.md](校正说明.md) · 幻灯片原文：[幻灯片原文.md](幻灯片原文.md)
> 校正原则：只改能由现场照片、上下文或公开资料明确判定的错误；无法复原的听写保留 `〔?〕` 并列入存疑，不臆造。

**标记约定**：`〔…〕` = 补全或无法逐字复原（不属于听写原文，不可逐字引用）；`〔?〕` = 完全无法复原。
置信度：高 = 含义有幻灯片原文或公开资料直接支撑（不等于逐字听写）；中 = 由上下文与术语还原；低 = 仅能确定大意。

## 一、本场信息

| 项目 | 内容 |
| --- | --- |
| 环节 | 串场 / 报告 / 问答，分别给起止时间 |
| 讲者 | 中英文姓名、职称 |
| 单位 / 团队 | 院系、实验室、职务 |
| 报告题目 | 幻灯片标题页写法；主持人口播写法若不同，一并列出 |
| 会议场次 | 会议名 + 论坛名 + Session 名 |
| 主持人 | 声纹编号或姓名 |
| 其他发言 | 声纹编号、身份判断、依据 |
| 时长 / 片段 | 总时长、逐句条数 |
| 现场照片 | 张数与编号区间 |
| 主题 | 一句话概括报告框架 |

> 原记录与订正说明（如讲者、单位、题目与原稿不同，在此交代一句）。

## 二、纪要摘要（校正并补全）

按报告结构分节；每个要点尽量带「（图 N）」。
数字、结论只写有证据的部分；口播独有的判断写「口播称…」；幻灯片独有的结论写「幻灯片：…」。

## 三、逐句校正

> 校正后文本为编辑整理版，不是逐字听写；`〔…〕` 处不可逐字引用。

| 时间 | 说话人 | 校正后 | 置信度 | 依据 / 主要修正 |
| --- | --- | --- | --- | --- |
| `00:00:00` | 主持人 | … | 高 | `原文错误` → 校正；依据（图 N / 官网 / 发音） |

## 四、幻灯片要点（含补全标注）

| 图 | 要点 |
| --- | --- |
| N | 标题；关键句；数字与单位；`〔补〕` 标注被遮挡后补全的部分 |

## 五、存疑与未决

1. **<疑点>**：现状（录音/照片/来源各支持什么）→ 可能的解法（回听/查论文/问用户）。
```

## 2. `校正说明.md`

```markdown
# 第 N 场报告校正说明

> 对象：原始转写与自动纪要；产物：校正版、幻灯片原文
> 时间 / 依据：照片编号区间、原始转写、公开资料

## 1. 结论概要
1. 讲者身份订正
2. 题目（口播 vs 页面）
3. 术语订正
4. 数据补全
5. 保持存疑

## 2. 方法与证据优先级
| 优先级 | 证据 | 用途 |
| 1 | 现场照片 | … |
| 2 | 原始转写/时间戳 | … |
| 3 | 官方资料 | … |
| 4 | 标准与术语 | … |
| 5 | 上下文语法 | … |

判定规则：「高/中/低」定义 + 本场分布。

## 3. 讲者与题目订正
| 项目 | 原记录 | 订正 | 依据 | 置信度 |

## 4. 术语与缩写订正（择要）
| 原听写 | 订正 | 依据 | 置信度 |

## 5. 数字、单位与结论的订正和补全
| 项 | 原记录 | 订正/补全 | 依据 |

## 6. 缺失内容的补全（原纪要未覆盖）
1. …

## 7. 存疑清单
| # | 存疑点 | 现状 | 可能的解法 |

## 8. 外部核对来源
- 论文/官方页/新闻/标准，逐条 URL；标注「可读到什么程度」（摘要/全文/仅检索结果）

## 9. 与其它文件的关系
- 原始转写：保留；文首指针
- 校正版 / 幻灯片原文：用途
- 会议纪要第 N 节：已重写，其余节未动
- 汇总转写：加指针；场次说明与发言人表如改动，逐条列出
```

## 3. `幻灯片原文.md`

```markdown
# 第 N 场报告 · 幻灯片原文（现场照片提取）

> 来源：images/ 下 N 张照片（编号区间）；用途：校正证据
> 方法：裁剪幕布 → 放大 → 逐块识读；`(?)` = 模糊/遮挡/只能确定大意；`〔推断〕` = 可读片段合并

**照片顺序即放映顺序**：N 封面 → N 背景 → …

### 图 N｜HH:MM:SS
**幻灯片标题**：…
- 逐字文本
- 图形关系（箭头、分组、图例）
- 关键数字与单位

## 复核要点
| 项 | 值 | 出处 |

## 易混点提示
1. …
```

## 4. 修改日志的列定义

| 列 | 内容 | 要求 |
| --- | --- | --- |
| 位置 | 时间戳 / 段号 / 文件行 | 可定位 |
| 原文 | 原始 ASR 的关键片段 | 不改写 |
| 校正 | 修改后的文本 | 只写到证据支持的程度 |
| 类别 | 身份/题目、术语缩写、数字单位、语法、说话人口误、其他 | 单选 |
| 证据 | E1–E6 + 具体出处（图 N、URL、语法点） | 可复核 |
| 置信度 | 高/中/低 | 与正文一致 |

## 5. 置信度与标记

| 标记 | 含义 | 读者应如何理解 |
| --- | --- | --- |
| 高 | 含义有图片/权威来源直接支撑 | 可引用含义，仍非逐字 |
| 中 | 由术语、上下文、发音线索还原 | 可引用但注明「编辑整理」 |
| 低 | 仅能确定大意 | 只作导读，不作引用 |
| `〔?〕` | 完全无法复原 | 明确不确定 |
| `〔…〕` / `〔补〕` | 补全（非听写原文） | 不得当作讲者原话 |

## 6. 原始件与指针的写法

- 原始 `转写.md` 文首加一行：
  `> 本文件逐句保留原始语音识别结果，未改写；本场信息表与说明第 N 条已按校正结果同步订正。校正版见 [转写_校正版.md](转写_校正版.md)，依据见 [校正说明.md](校正说明.md)。`
- 汇总 `转写记录.md` 在场次起始处加：
  `校正记录：[转写_校正版.md](…)、[校正说明.md](…)、[幻灯片原文.md](…)`
- 自动纪要的对应小节前加：
  `> 本节已按现场照片与公开资料校正（YYYY-MM-DD）。逐句校正版见 …`
