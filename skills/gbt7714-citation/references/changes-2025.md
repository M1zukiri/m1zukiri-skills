# GB/T 7714—2025 与 2015 版对照（升级速查）

> 当用户给出"参考文献格式按 GB/T 7714"或已有旧版条目需要升级时使用本文件。只列**影响著录写法的差异**；术语学理层面的变动（如"专著→图书"）在条目写法上体现不大，一并注明以免困惑。

## 1. 一句话概览

2025 版（2025-12-02 发布、2026-07-01 实施，替代 2015 版）的核心改动：**英文作者姓氏不再全大写；电子资源先判文献本体类型再补 `/OL`；新增预印本 PP、数据集 DS、档案 A、地图 CM 四种类型；标准 [S] 著录大幅简化；学位论文首次强制著录引文页码；"永久标识符"取代"数字对象唯一标识符"概念。**

## 2. 影响条目写法的差异表

| 项目 | 2015 版 | 2025 版 | 例子 |
|---|---|---|---|
| 西文作者姓氏 | 全大写 | 首字母大写，其余小写 | `EINSTEIN A` → `Einstein A` |
| 汉语拼音人名 | 中国著者姓名不得缩写 | 姓全大写；名可全称（推荐）或缩写为拼音首字母 | `Li Jiangning` 或 `LI J N` 均合法 |
| 电子资源归类 | 单独成类（4.6 电子资源） | 拆分到各文献类型；先判本体再补载体 | 在线期刊论文 → `[J/OL]`（不是 `[EB/OL]`） |
| 文献类型"普通图书" | 普通图书 M | 图书 M | 名称变，代码不变 |
| 文献类型"舆图" | 舆图 GM | 地图 CM | 名称与代码均变（GM→CM） |
| 文献类型"电子公告" | EB | 网站、网页 EB | 名称变，代码不变 |
| 新增文献类型 | — | 预印本 PP、数据集 DS、档案 A | arXiv → `[PP/OL]` |
| 电子资源载体 | — | 新增"缩微资料 MM" | |
| 标准 [S] | 著录责任者（制定单位）、出版地、出版者等 | 仅 `标准编号 标准名称[S]` | `GB/T 3792—2021 信息与文献 资源描述[S].` |
| 学位论文 | 页码"可选" | 引文页码**有则必备**（2025 首次强制） | `2022: 87.` |
| 图书馆资料引文页码 | 任选 | 有则必备 | 图书/会议/析出文献页码一般要写 |
| 日期表述 | 公告日期、更新日期、引用日期 | 创建/发布或修改日期、引用日期；统一 `YYYY-MM-DD` | `(2023-09-10)[2025-07-15]` |
| 非电子资源引用日期 | 可著录 | 取消 | 纸质文献不写访问日期 |
| 数字对象唯一标识符 | DOI | 永久标识符（PID，含 DOI/URN/CSTR） | DOI/CSTR 均为 PID |
| "专著""专著中的析出文献" | 专著 | 图书、图书中的析出文献 | 术语变，格式基本不变 |
| 无卷号期刊 | `年, (期)`（部分解读） | `年(期): 页`，中间不加逗号 | `2013(1): 56-75.` |
| 期刊增刊 | — | 中文 `45(增刊1)`、英文 `45(S1)` | |
| 合并期号/卷号 | 用 `-` 连接 | 用 `/` 分离 | `46(1/2)` |
| 无页码文章编号 | 可省 | 按页码著录 | `2023, 267: 147370.` |
| 文章题名 | 可著录并列题名 | 按信息源著录、不再著录并列题名；无题名自拟并置 `[ ]` | |
| 题名副题名 | — | 用 `:` 连接，不提倡破折号"——" | |
| 章节结构 | 参考文献表 + 参考文献标注法两章 | 合并为第 9 章"参考文献标引体系编制法" | 无格式影响 |
| 作者截断 | 前后一致（前 3 + 等/et al） | 不变 | |

## 3. 升级一个旧条目的三步法

1. **作者行**：把西文名姓氏从全大写改为首字母大写（`PEEBLES P Z` → `Peebles P Z`）；拼音名 `LI J N` 可保留或改 `Li Jiangning`。
2. **类型与载体**：检查是否应补 `/OL`（在线文献却写 `[J]` 时）；检查是否为 `[EB/OL]` 误用（在线学位论文应为 `[D/OL]`）；检查是否应为 2025 新增类型（arXiv → `[PP/OL]`、开放数据 → `[DS/OL]`）。
3. **必备信息补漏**：学位论文补页码；电子文献补 URL（若缺）与 DOI（URL 不含时）；标准删去制定单位/出版地/出版者；检查日期格式 `YYYY-MM-DD`。

## 4. 最新版标准信息（供向用户说明）

- 标准名称：《信息与文献 参考文献著录规则》
- 编号写法：官方用一字线 `GB/T 7714—2025`（短横线 `GB/T 7714-2025` 为便捷写法）
- 发布：2025-12-02（国家市场监督管理总局、国家标准化管理委员会）
- 实施：2026-07-01，全面替代 GB/T 7714—2015
- 性质：推荐性国家标准（GB/T）；参考/对标 ISO 690:2021
- 过渡：2026-07-01 之前定稿的稿件可按 2015 版；之后所有投稿、答辩、见刊稿件应按 2025 版，并以目标期刊"投稿须知"为准（部分期刊已将 2025 版作为唯一标准）

## 5. 常见误解澄清

- **"GB/T 7714 是强制标准"** → 否，推荐性（GB/T），但国内各期刊、学位授予单位普遍要求按其执行。
- **"标准示例用全角标点"** → 标准正文著录用符号为半角（`. , : ; // ( ) [ ]`）；中文期刊排版常转全角（`， ： （ ）`），以刊物要求为准。
- **"所有在线文献都写 URL + 引用日期"** → 只有动态资源（网页、预印本、数据集、网络首发）强制引用日期；电子图书/电子期刊/电子学位论文只需 URL（+ 永久标识符）。
- **"2025 版要求 DOI 必填"** → 电子资源**一般要求**提供永久标识符；URL 已含 DOI 时不重复标注。纸质文献不要求。
