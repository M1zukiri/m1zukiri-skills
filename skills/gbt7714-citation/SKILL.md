# 参考文献著录（GB/T 7714—2025）

把一篇文献的正确信息变成一条符合现行国标的参考文献条目。本 skill 只负责**文末参考文献列表的条目**——生成、格式化、核对、从 2015 版升级。不负责检索文献本身（那是 lit-search / nature-citation / litian-academic-search 的事）、不负责正文中的标引位置（如需正文标注说明，见文末）。

核心心智模型：**先判定文献本体类型，再补载体标识**。在线资料不因来自网络就一律写成 `[EB/OL]`——在线期刊论文是 `[J/OL]`，在线图书是 `[M/OL]`，在线学位论文是 `[D/OL]`，在线报告是 `[R/OL]`，在线数据集是 `[DS/OL]`，在线预印本是 `[PP/OL]`。`OL` 只是"联机在线获取"的载体含义，不决定格式。

## 决策流程（每次生成均按此走）

1. **确定文献本体类型**（下表"常见说法 → 类型"判定；拿不准时按用户描述的实际出版物形态判断，而不是按用户给的链接判断）。
2. **判断载体**：纸质 → 仅类型码（如 `[J]`）；电子/在线 → 类型码 + `/OL`（如 `[J/OL]`）；其他载体（光盘 `CD`、缩微 `MM`、磁盘 `DK`、磁带 `MT`）同理使用对应码。
3. **选模板**（见下）；**字段的必备性**：必备（缺了就不完整）、有则必备（文献里有就写）、可选、电子资源必备。不要臆造字段，也不要省略文献上实际载有的必备信息。
4. **排标点**：按"标点规则"一节；页码前永远是冒号 `:`。
5. **自检**：跑一遍"自检清单"，重点核对类型码、作者截断（`等`/`et al`）、日期格式、DOI/URL、题名原文（不添加并列题名）。

陷阱提示：arXiv 论文是**预印本 `[PP/OL]`**，不是期刊 `[J]`——它尚未通过同行评审，也不宜直接写成正式期刊论文；除非用户明确说明该文已刊发（此时提供正式刊发信息并改用 `[J]`）。CNKI/万方的学位论文是 `[D/OL]` 不是 `[EB/OL]`。微信公众号文章、知乎文章、B 站视频等属于网站、网页 `[EB/OL]`。

每个模板的完整字段说明、必备性表、中英文标准示例、以及"无责任者从题名开始""无出版地 `[S.l.]`""合并期号用 `/`""文章编号当页码"等所有变体，都在 [references/formats-all.md](references/formats-all.md)，一律先查它，不要凭记忆套模板。

## 标点规则（最容易出错的地方）

- **页码前用冒号 `:`**：`2022: 87.`、`52(11): 1518-1523.`。绝不用句点。
- **卷、期、页连接**：`年, 卷(期): 页`（2012, 52(11): 1518-1523）；无卷号 `年(期): 页`（2013(1): 56-75，中间加括号、不加逗号）；无期有卷 `年, 卷: 页`（1992, 359: 605-609）；合期号 `年(期/期): 页`（2024, 46(1/2): 3-8）；增刊 `年, 卷(增刊1): 页` / 英文 `年, 卷(S1): 页`；无页码但有文章编号 → 文章编号按页码著录（2024, 45(增刊1): 730570）。
- **页码范围**用连字符 `-`（1518-1523）。
- **责任者间**用逗号 `,`（中文、英文一致）。析出文献与其出处用 `//` 连接。题名与其他题名信息用 `:` 连接（副题名不提倡用破折号"——"）。标准编号与标准名称之间用空格。
- **日期**：电子资源日期一律 `YYYY-MM-DD`；创建/发布/修改日期用圆括号 `( )`；引用日期用方括号 `[ ]`；同一条里先 `(修改日期)` 后 `[引用日期]`。纸质文献不要写访问日期（2025 版取消了非电子资源的引用日期）。
- **永久标识符**（PID，含 DOI、URN、CSTR）：放在条目最后，通常是 `获取和访问路径. 永久标识符.`；若 URL 已包含 DOI，则不重复标注 DOI。电子资源一般要求提供。
- **著录用符号全部半角**（`. , : ; // ( ) [ ]`）。标准正文如此；部分中文期刊排版时会转全角（`， ： （ ）`），以目标期刊投稿须知为准——默认输出半角。

## 姓名规则

- **英文/西文**：姓全部著录、首字母大写，其余小写（2025 版起不再全大写：`EINSTEIN A` → `Einstein A`）；名可缩写为首字母并大写、缩写后可带可不带点、不加句点（`Einstein A`）；≥3 作者时前 3 位 + `et al`，≤3 全员著录。
- **中文**：照原文著录，不要加"（明）"等朝代国别前缀；≥3 作者时前 3 位 + `等`。
- **汉语拼音人名**：姓全大写（拼音），名用全称或缩写为每个汉字拼音首字母均可——`Zhang Weidong` 与 `ZHANG W D` 均为合法，推荐全称（GB/T 28039—2011）。
- **作者一律姓前名后**；中文文献的"等"、英文的 `et al` 前用逗号：`汤万金, 杨跃翔, 刘文, 等.`。
- **机关团体**：由上至下分级著录，上下级间用 `.` 分隔（中文机构名除外，中文机构不用 `.` 分级）。
- **无责任者或责任者不明**：从题名开始著录；题名需自拟时置于 `[ ]` 内（如 `[《昨日之歌》图书封面][EB/OL].`）。
- 译者等"其他责任者"著录方式：`译者名, 译`，位置在题名之后（`博伯尔. 银行业的未来与人工智能[M]. 徐超, 译.`）。

## 自检清单（生成或核对后逐项确认）

- [ ] 类型码正确（先判本体类型；arXiv=PP，CNKI 学位论文=D，网页=EB，别一律 `[EB/OL]`）
- [ ] 载体码正确（在线加 `/OL`）
- [ ] 作者数量与截断正确（≤3 全列；>3 前 3 + 等/et al）
- [ ] 英文姓氏大小写正确（首字母大写，非全大写）
- [ ] 页码前是冒号；卷期页连接符合"年, 卷(期): 页"体系
- [ ] 日期 `YYYY-MM-DD`；创建/修改日期圆括号、引用日期方括号；纸质文献无引用日期
- [ ] 题名照信息源原文，不加并列题名；副题名用冒号
- [ ] 标准条目为 `标准编号 标准名称[S].`（不含标准制定单位、出版地、出版社）
- [ ] 学位论文/会议/图书析出等"有则必备"的引文页码已著录
- [ ] [J/OL] 类有 URL；URL 未含 DOI 时已补 DOI，已含则未重复
- [ ] URL 指向具体资源页面而非平台首页
- [ ] 中文文献条目用半角标点（若目标刊物要求全角则整体转换）
- [ ] 编号按正文首次出现顺序连续（核对整表时）

## 升级与核对既有条目

若用户提供 2015 版格式的旧条目，升级为 2025 版只需改三处典型差异（其余不变）：英文作者姓氏全大写 → 首字母大写；`著者` 系统术语不变；检查是否缺 2025 版新增必备信息（学位论文页码、URL/DOI）。完整对照见 [references/changes-2025.md](references/changes-2025.md)。

## 自动化（可选）

网络可用时，可用 [scripts/gbt7714_fetch.py](scripts/gbt7714_fetch.py) 从 DOI、arXiv ID、或 URL 抓取元数据并直接输出 GB/T 7714—2025 条目（期刊/图书/学位论文/预印本/数据集常见类型均可，纯标准库实现）：

```
python scripts/gbt7714_fetch.py --doi 10.1038/nature13308
python scripts/gbt7714_fetch.py --arxiv 2301.12345
python scripts/gbt7714_fetch.py --url https://arxiv.org/abs/2301.12345 --type pp
```

脚本输出为 JSON（含字段与格式化条目）；网络不可用时降级为输出已知元数据由本 skill 按模板排版。所有字段在采纳前须人工核对（元数据源偶尔含错），不要机械照抄标题大小写。

## 正文标注（仅作提示，非本 skill 主体）

用户若问正文标引：GB/T 7714 两套体系（顺序编码制、著者-出版年制）同文内不得混用。顺序编码制：正文右上角 `[1]`，同处多篇 `[3,7,9]`、连续 `[2-3]`；同一文献多次引用只编 1 个号，页码处理按目标刊物（序号外上标 `[1]13` 或文献表不重复著录页码的脚注法等三种）。参考文献表按正文序号排序。
